* Sinolor Theme

Sinolor themes is a theme package whose code is based on [[https://github.com/protesilaos/modus-themes][modus-themes]].

The original Sinolor themes draw from [[http://zhongguose.com/][CHINESE COLORS]].  The EVA
series instead follows each unit's signature armor colors and uses its
pilot's colors as secondary accents.

| Name           | Description                             |
|----------------+-----------------------------------------|
| sinolor-elysia | To Romantic Unfailing Elysia            |
| sinolor-eva-00 | Evangelion Unit-00 and Rei Ayanami (light) |
| sinolor-eva-01 | Evangelion Unit-01 and Shinji Ikari     |
| sinolor-eva-02 | Evangelion Unit-02 and Asuka Shikinami Langley |
| sinolor-palace | The Palace Museum                       |

** Installation

1. Clone this repository

#+begin_src bash-ts
git clone https://github.com/dalugm/sinolor-themes.git
#+end_src

2. Add =sinolor-themes= to load-path.

#+begin_src elisp
(add-to-list 'load-path (expand-file-name "path/to/sinolor-themes"))
(require 'sinolor-themes)
#+end_src

** Usage

#+begin_src elisp
(load-theme 'sinolor-eva-01 t)
#+end_src
